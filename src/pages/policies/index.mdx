# Policies and support

## Software

PyMOL's open-source build is free and works for everything this course
requires. Install it before [week 1's session](/sessions/01-getting-started/);
if it won't run on your machine, the lab machines have it, and Idris can help
you find a slot.

## Late work and extensions

Work submitted after its deadline loses 5% of the available mark per day, to
a maximum of five days, after which it is not accepted. If something outside
your control is going to make a deadline, email Marisol *before* the
deadline — extensions agreed after the fact are much harder to grant fairly.

## Academic integrity and AI tools

Using an AI tool to help write code, draft prose, or explore a structure is
allowed and, for the PyMOL scripting in particular, expected — it's a normal
part of how this work gets done outside a classroom too. What's required is
that you can defend everything you submit: if asked, you must be able to
explain why a script does what it does or why a structural claim is correct,
independent of what generated the first draft.

Declare non-trivial use of an AI tool in the assessment it touched (Assignment
1 and the final project both ask for this in their spec). Undeclared use that
a marker discovers is treated as a straightforward integrity breach, not a
disclosure problem — declare early and it is a non-issue.

## Getting help

For a question about a specific structure, a script that won't run, or
anything hands-on: ask Idris, in session or by email. For a question about
the course itself — deadlines, extensions, weighting, what a brief is
actually asking for: ask Marisol. See [people](/people/) for both.
